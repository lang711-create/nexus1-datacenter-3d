# NEXUS-1 // Vercel Public Website Deployment Package

This ZIP archive (`nexus1_vercel_deployment.zip`) is pre-configured with `index.html`, `vercel.json`, and `manifest.json` so you can deploy directly to your **Vercel** account with zero build steps or Git setup required.

## 1. Fastest Way: Deploy via Vercel Drop (10 Seconds, No Git/CLI Needed)
1. Open **[https://vercel.com/drop](https://vercel.com/drop)** in your browser and sign in to your Vercel account.
2. Drag and drop **`nexus1_vercel_deployment.zip`** directly onto the Vercel Drop page (you do not even need to unzip it!).
3. Choose your team/account, name your project (e.g., `nexus1-datacenter-3d`), and click **Deploy**.
4. In ~5 seconds, Vercel will publish your interactive 3D Data Center Academy to a permanent public URL (`https://nexus1-datacenter-3d.vercel.app`) that anyone can open on desktop or mobile!

## 2. Alternative: Deploy via Vercel CLI
If you have Node.js installed on your computer:
1. Unzip this folder and open a terminal inside it.
2. Run `npx vercel --prod` and follow the prompt to link to your Vercel account.
